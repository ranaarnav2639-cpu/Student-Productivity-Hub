# Student Productivity Hub

**Plan Smart • Study Hard • Achieve More**

Student Productivity Hub is a simple, interactive and responsive web application designed to help students manage their daily academic activities, stay organized and improve their productivity.

It provides essential study-management tools in one place, including task management, a Pomodoro study timer, quick notes, daily progress tracking and motivational quotes.

##  Features

### 1.  Dashboard
- Displays a personalized greeting based on the current time.
- Shows the current date.
- Displays total tasks, completed tasks and remaining tasks.
- Calculates the overall task completion percentage.
- Provides a visual progress bar to track daily productivity.

### 2.  To-Do List
- Add new tasks easily.
- Mark tasks as completed using checkboxes.
- Delete tasks when they are no longer required.
- Automatically updates task statistics.
- Saves tasks in the browser using Local Storage.

### 3.  Pomodoro Study Timer
- 25-minute focus session.
- 5-minute break session.
- Start, pause and reset timer options.
- Switch between focus and break modes.
- Displays notifications when a session is completed.

### 4.  Quick Notes
- Write important academic notes and reminders.
- Save notes directly in the browser.
- Automatically loads previously saved notes.
- Uses Local Storage to preserve notes after refreshing the page.

### 5.  Daily Motivation
- Displays motivational quotes.
- Generates a new random motivational quote whenever the user clicks the button.
- Encourages students to maintain consistency and focus.

3. Locate the `index.html` file.

##  Data Storage

This project uses the browser's **Local Storage** to save:
- Student tasks (`studentTasks`)
- Personal notes (`studentNotes`)

This allows saved tasks and notes to remain available after refreshing or reopening the website in the same browser.

**Note:** Data is stored locally in the browser and is not synchronized across different devices or browsers.

##  Responsive Design

The website uses CSS Grid, Flexbox and media queries to provide a responsive layout that adapts to different screen sizes, including desktops, tablets and mobile devices.
